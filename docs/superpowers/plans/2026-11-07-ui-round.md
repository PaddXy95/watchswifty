# WatchSwifty UI Round 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Branding, footer, centered login, mobile layout with burger menu, loading bar, "Gesamte Serie gesehen", private comments, cleaner import candidates, git remote and Docker README.

**Architecture:** Server-rendered Elementary components + CSS only (no custom JS); htmx indicator/boost for loading feedback; comments stored per user (`user_titles.comment`, new `season_notes` table) and written through `WatchService`.

**Tech Stack:** unchanged (Vapor 4, Fluent/SQLite, Elementary 0.9.0, ElementaryHTMX2, htmx 2.0.11, Swift Testing).

**Spec:** `docs/superpowers/specs/2026-11-07-ui-round-design.md` (+ base spec `2026-11-07-watchswifty-design.md`).

## Global Constraints

- No custom JavaScript; only htmx attributes and CSS.
- Brand spelled exactly `WatchSwifty`; tab title `"<Seite> · WatchSwifty"`.
- Footer copy exactly `Built with Swift and Vapor with ❤️`; links `https://www.swift.org`, `https://vapor.codes`; right side `GitHub` → `https://github.com/PaddXy95/watchswifty`.
- Mobile breakpoint: `max-width: 700px`; desktop navigation unchanged.
- Comments: private per user, trimmed, empty = delete, max 2000 characters → 422 „Kommentar darf höchstens 2.000 Zeichen haben.“
- Image name `ghcr.io/paddxy95/watchswifty`; git remote `origin` = `https://github.com/PaddXy95/watchswifty.git`; never push.
- Existing tests keep passing; update assertions that pin the old lowercase brand.

## Review Focus

1. Comment with HTML/markup and line breaks → shown escaped, line breaks kept; 2001 characters → German 422 message. Test in Task 4.
2. „Gesamte Serie gesehen“ on a series with specials and unaired episodes → only aired regular episodes get marked. Test in Task 3.
3. Phone: logout and admin link reachable through the burger menu. Test in Task 1.
4. Boosted link click (`HX-Request` + `HX-Boosted`) with expired session → `HX-Redirect: /login`, not a login page inside the body. Test in Task 2.
5. User B never sees user A's series/season/movie comments. Test in Task 4.
